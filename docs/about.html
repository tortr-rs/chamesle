About

People usually don't leave Linux because of anything big. It's something small: a driver, an app they can't find, a menu that isn't where they expected. So the idea is simple. Make a system that looks like what people know, has the drivers and apps already sorted, and stays out of the way.

It's a small project, so things move at that speed.

Roadmap

0.1Xfce live ISO, Windows-like layout, Flathub, firmware and drivers. done
0.2Installer (dual boot, encryption), the system on apk and the Chamesle repo, .deb and .rpm support. done
0.3A GNOME edition. (The update notifier and driver manager came early, in 0.2.) out
0.4Updates can't break your computer. Before every update Chamesle takes a snapshot of the system, and if something goes wrong you pick "before the update" in the boot menu and you're back. Only the system is snapshotted, never your files, and only the last 3 are kept, so they don't eat your disk. Plus the first Flavor: Chamesle Astro, for astronomy.
0.5A KDE Plasma edition, and help moving from Windows: it copies your documents, pictures and bookmarks over, and suggests the Linux apps for the Windows ones you used.
0.6A server edition with a text installer, and a gaming Flavor: Steam, Proton and controllers ready to go.
0.7A better store: screenshots, ratings, updates in the background, and firmware updates for your BIOS and SSD.
0.8Chamesle's own apps in every language, and a pass on accessibility: screen reader, high contrast and large text from the first boot.
0.9Release candidate: no new features, just fixes and testing on real hardware.
1.0Godrick.

No dates for these. Once 1.0 is out, there's a new ISO every 6 months, and the version names follow Elden Ring's bosses: Margit until 1.0, then Godrick, Rennala and Radahn.

Stable rolling

Chamesle updates every week, like a rolling distro, but slowly on purpose: a new version waits a while before it goes out, and every week's updates have to install and boot in a test machine first. The kernel stays on the long-term support line.

How it's built

Each ISO is made by one script, build.sh, from a list of packages per edition. The init system is dinit, the boot is GRUB with a small initramfs of our own, and the desktop look is the Fluent theme and icons. All of it is in the GitHub repo if you want to build your own.

The package repo is built by our own tools: every package is converted to apk, signed with the Chamesle key and indexed. The tools are in tools/repo/.

Help out

  • Try it and report what breaks.
  • Test it on your hardware, especially laptops and anything with NVIDIA.
  • Pull requests are welcome. Small ones are easier to review.
  • Tell a friend who's thinking about leaving Windows.

License

Chamesle's own code is open source on GitHub. The packages keep their own licenses; source code for every package is available on request (open an issue). Some packages, like firmware and the NVIDIA driver, are not open source.
