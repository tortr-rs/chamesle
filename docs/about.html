About

Chamesle is written by one person.

Chamesle is pronounced /tʃa.mes.le/. It's a small project, so things move at that speed.

Chamesle used to be something else

Until this month, Chamesle was a desktop distro for people leaving Windows, put together from other systems' packages. It had eight desktops, a glass look, a setup program called Jiggity and releases up to 0.7. We dropped all of it on November 14, 2026. It was a lot of work to keep up and not much of it was ours.

The old releases are no longer supported. Nothing from them carries over, and the new system shares no code with them. The old code is still on GitHub if you want to look.

The new one

It starts from the other end: write the small things ourselves and take as little as possible from anyone else.

  • rifle, the coreutils, from scratch, in one C file. It is tested against GNU's tools: 810 cases pass.
    The Rifle Shoots down the GNU
    Unfortunately the GNU herd got so big the rifle doesn't have enough ammo to shoot all of it down. gmake, to build musl, and the kernel's build tools are still GNU.
  • Winchester, the init. A shell script that runs /etc/rc and keeps the gettys alive.
  • SPAS, the package manager. Its command is hoard. It reads Gentoo's repository and runs the ebuilds, on the musl profile. hoard sync fetches the tree.
  • chamesle-disk and chamesle-chroot, two small helpers for installing: the first runs cfdisk and makes a vfat boot partition and a ZFS root, the second chroots with /proc, /dev and the rest mounted. The install itself stays by hand.
  • musl for the C library, mksh for the login shell and /bin/sh, a shell script init in the FreeBSD style (/etc/init.conf, services in /etc/rc.d), limine to boot.
  • Linux 6.18 LTS as the kernel, prebuilt. Nobody here builds a kernel.

No GNU software goes in the system. The exceptions are build tools: gmake, bison, flex and m4, which some packages need while they are being built. They are not part of what gets installed.

Roadmap

The plan is on the home page. There are no dates.

A desktop is not planned yet. X22, our X server, is a separate project and has its own site.

Side project

Meet Chum

Chum is a sunfish. He is the mascot of Chamesle, mostly because nobody else wanted the job.

He can't see. He doesn't have a tail fin, so he mostly drifts. He has never once been asked for his opinion, and he has one about everything.

You won't find him on the front page. That's on purpose. If you're reading this, you looked around, and Chum respects that.

Favourite food: jellyfish, and whatever drifts past his mouth. Favourite package: sl. Least favourite: the Konami code. Don't ask.
