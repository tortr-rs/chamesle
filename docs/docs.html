First steps

When the live session starts you're logged in as live. Some things worth knowing:

  • The Windows key opens the start menu. Type to search.
  • Wi-Fi is the network icon in the bottom right.
  • The terminal is in the menu under System, or right-click the desktop.
  • The live user can use sudo without a password.
  • Nothing you do in the live session is saved when you restart, unless you save it to a disk or USB stick.

Installing Chamesle

Boot the USB stick, then double-click Install Chamesle on the desktop.

  1. Language: pick yours from the list.
  2. Timezone: click where you are on the map.
  3. Keyboard: pick your layout, there's a picture of it and a box to try it.
  4. User account: your name, a username, a password and a name for the computer.
  5. Installation type: “Automated” erases a disk and sets everything up, with encryption if you tick it. “Manual” lets you choose partitions yourself. To keep Windows, pick Manual, open GParted from there, shrink the Windows partition, and install into the free space.
  6. Summary: check it and click Install. Restart when it's done and take the stick out.

Back up anything important first. Shrinking Windows works fine almost always, but “almost” isn't “always”. If Windows uses BitLocker, turn it off (or have the recovery key) before you start.

Installing apps

For desktop apps, use Flathub. You can browse it at flathub.org, click Install there, and it opens on your computer. Or in a terminal:

flatpak search obs
flatpak install flathub com.obsproject.Studio

For everything else there's the system package manager. See the packages page. Got a .deb or .rpm? From 0.2 you can double-click it.

Updates

Flathub apps:

flatpak update

The system, from 0.2:

sudo apk upgrade

Updates come out every week. On 0.1 it's sudo xbps-install -Su. An update notifier is coming in 0.3 so you don't have to remember.

Services

Chamesle uses dinit instead of systemd. Services are small text files in /etc/dinit.d/. You control them with dinitctl:

dinitctl listwhat's running
sudo dinitctl start sshdstart a service now
sudo dinitctl stop sshdstop it
sudo dinitctl enable sshdstart it on every boot
sudo dinitctl disable sshddon't

A service file looks like this:

type = process
command = /usr/bin/sshd -D
depends-on = network

Hardware

Firmware for most Wi-Fi cards, graphics cards and Bluetooth adapters is already included, and Intel and AMD graphics work out of the box. Printers are handled by CUPS: open Printers from the menu or go to http://localhost:631.

NVIDIA cards work with the open-source driver. The proprietary one is in the repo (nvidia), and the driver manager coming in 0.3 will set it up for you.

FAQ

Is it free?

Yes. No cost, no ads, no account, no tracking.

Can I install it next to Windows?

Yes, from 0.2. The installer finds Windows, makes room next to it, and you pick which one to start at boot. See Installing Chamesle.

Will my games work?

Most Steam games do, through Proton. Install Steam from Flathub, then turn on Steam Play in its settings. Games with kernel-level anti-cheat (Valorant, some battle royales) won't.

Can I run Windows programs?

A lot of them, with Wine or Bottles (on Flathub). Check WineHQ's app database for how well a specific program works.

Why dinit and not systemd?

It's small, fast, and easy to understand. A service is a five line text file. For a desktop you won't notice the difference, except maybe that it boots quicker.

Is it based on another distro?

No, Chamesle is independent: glibc, dinit, apk packages from the Chamesle repo signed with our key, and its own installer setup, look, defaults and tools like pkgimport.

I found a bug.

Great, sort of. Please open an issue with what you did, what you expected, and what happened instead. A photo of the screen helps if it's a boot problem.
