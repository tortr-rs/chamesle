Install

Chamesle is installed by hand. That is the design: like Gentoo or Linux From Scratch, you partition the disk, build the base system into it and set up the boot loader yourself. The handbook has every step. There are two ways to start.

From a running Linux

On any Linux system with mag and chamesle-bootstrap, mount the target disk and run the bootstrap into it. This is chapter 5 of the handbook, Installing by hand.

mag sync
export MAG_REPO=/path/to/repo:/usr/pkgsrc
chamesle-bootstrap -n yourhostname /mnt

It builds the base system from source into /mnt, kernel included, and takes a while. Then you set up fstab, the root password and limine, as the handbook says.

From the live ISO

You build the ISO yourself with iso/mkiso (handbook chapter 4) and boot it.

iso/mkiso -r $HOME/src/mag/repo:/usr/pkgsrc

The ISO is a live system with mksh, vim, mag with our recipes, chamesle-bootstrap, chamesle-chroot, chamesle-disk (cfdisk, then vfat for boot and ZFS for the root), the disk tools (sfdisk, mkfs.ext4, mkfs.fat, zpool, zfs) and the handbook in /usr/share/doc/chamesle/. It boots on BIOS and on UEFI machines with limine, from a CD or a stick. Install from it with chapter 5.

The machine that builds needs mksquashfs, xorriso, zstd, bsdcpio, limine and mag. Building everything from source takes a while, and LLVM is the long part. mkiso builds a root with chamesle-bootstrap, copies the overlay over it, makes the initrd, packs the root into a zstd squashfs and writes the ISO with xorriso.

Trying it in QEMU

qemu-system-x86_64 -cpu max -m 1G -cdrom chamesle.iso -boot d
qemu-system-x86_64 -cpu max -m 1G -bios /usr/share/qemu/edk2-x86_64-code.fd -cdrom chamesle.iso

The first boots it as BIOS, the second as UEFI.

Older Chamesle ISOs

Anything older with Chamesle's name on it, such as the 0.7 ISO, is the old Debian-based distro. It is a different system and gets no updates.
