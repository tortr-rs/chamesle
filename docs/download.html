Boot it from a USB stick and try it without touching your disk. When you like it, double-click Install Chamesle on the desktop. It's still an early release, so back up anything important first. What's new.

What you need

  • a 64-bit PC from roughly the last 12 years (BIOS or UEFI both work)
  • 2 GB of RAM, 4 if you want lots of browser tabs
  • a USB stick of 4 GB or more

Secure Boot has to be turned off for now.

Making the USB stick

This wipes the stick, so copy anything you need off it first.

On Windows or macOS

Get balenaEtcher, pick the ISO, pick the stick, click Flash.

On Linux

Etcher works here too. Or from a terminal (check the device name with lsblk first, getting it wrong will wipe the wrong disk):

sudo dd if=chamesle-0.3.0-xfce-x86_64.iso of=/dev/sdX bs=4M status=progress conv=fsync

Ventoy

If you already use Ventoy, just copy the ISO onto the stick.

Booting it

Plug the stick in, restart, and open the boot menu. It's usually F12, F11, F8 or Esc right after you power on, depending on the computer. Pick the USB stick. You'll get a menu with a few choices:

Try or installthe normal one
Safe graphicsuse this if you get a black screen
Copy to RAMloads everything into memory so you can pull the stick out (needs 4 GB+)
Show boot messagesfor when something goes wrong and you want to see what

The live session logs in by itself as the user live. It has no password and can use sudo.

Checking the download

If you want to be sure the file isn't broken, compare its checksum with the one next to the download:

sha256sum -c chamesle-0.3.0-xfce-x86_64.iso.sha256

On Windows, certutil -hashfile chamesle-0.3.0-xfce-x86_64.iso SHA256 in a command prompt does the same.

In a virtual machine

VirtualBox, VMware, GNOME Boxes and QEMU all work. Give it 2 CPUs and 3 GB of RAM. With QEMU:

qemu-system-x86_64 -enable-kvm -m 3G -smp 2 -cdrom chamesle-0.3.0-xfce-x86_64.iso
