Download

Chamesle is one ISO for x86-64 machines. Write it to a stick, boot it, and install from it by hand with the handbook.

Check the download before you use it:

sha256sum chamesle.iso

Write it to a stick

Find the stick with lsblk and use its name, not a partition. This erases everything on it.

dd if=chamesle.iso of=/dev/sdX bs=4M status=progress conv=fsync

The stage

The system is also a stage tarball, 940 MB: musl, rifle, mksh, Winchester, gcc, python, perl, SPAS and sam. Unpack it into a new root as in the handbook. It is on the releases page, with its sha256.

What is on it

A live system with mksh, vim, SPAS and the Gentoo tree, chamesle-chroot, chamesle-disk (cfdisk, then vfat for boot and ZFS for the root), the disk tools (sfdisk, mkfs.ext4, mkfs.fat, zpool, zfs) and the handbook in /usr/share/doc/chamesle/. It boots with limine and logs in as root with no password.

What you need

An x86-64 machine with 2 GB of RAM and a disk to install on. The network comes up with DHCP on a wired card; wifi firmware is added with SPAS after the install, as the handbook says.

Try it in QEMU first

qemu-system-x86_64 -cpu max -m 2G -cdrom chamesle.iso -boot d
qemu-system-x86_64 -cpu max -m 2G -bios /usr/share/qemu/edk2-x86_64-code.fd -cdrom chamesle.iso

The first boots it as BIOS, the second as UEFI.

Then

Install it with chapter 3 of the handbook: partition the disk, copy the system, write the boot entry, reboot.

Older Chamesle ISOs

Anything older with Chamesle's name on it, such as the 0.7 ISO, is the old Debian-based distro. It is a different system and gets no updates.
