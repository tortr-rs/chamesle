Download

Chamesle is one ISO, for x86-64 machines, and one for 32-bit x86. Write it to a stick, boot it, and install from it by hand with the handbook. There is no stage: chamesle-bootstrap fetches the base from the repos while you install.

Check the download before you use it:

sha256sum chamesle.iso

Write it to a stick

Find the stick with lsblk and use its name, not a partition. This erases everything on it.

dd if=chamesle.iso of=/dev/sdX bs=4M status=progress conv=fsync

What is on it

A live system that logs in as root: mag with the keys and the repos, chamesle-bootstrap, chamesle-chroot, chamesle-disk, the disk tools (cfdisk, sfdisk, lsblk, blkid, mkfs.ext4, mkfs.fat, zpool, zfs, limine), dhcpcd and iwd for the network, the Intel wireless firmware, vim, and the handbook in /usr/share/doc/chamesle/.

What you need

A machine with 256 MB of RAM or more, a disk to install on, and a network connection: a cable works at once, wireless with iwctl. The packages come from the repos during the install.

Try it in QEMU first

qemu-system-x86_64 -m 1G -cdrom chamesle.iso -boot d
qemu-system-x86_64 -m 1G -bios /usr/share/qemu/edk2-x86_64-code.fd -cdrom chamesle.iso

The first boots it as BIOS, the second as UEFI.

Then

Install it with chapter 3 of the handbook: partition the disk, run chamesle-bootstrap /mnt, write the fstab and the boot entry, reboot.

The repo

Chamesle's own packages are at https://chamesle.org/repo/x86_64 and /repo/x86, signed with chamesle-20261118.rsa.pub.

Older Chamesle ISOs

The stages of 2026-11-17 and anything older with Chamesle's name on it, such as the 0.7 ISO, are earlier systems. They get no updates.
