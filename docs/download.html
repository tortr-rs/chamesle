Not sure which? Compare the editions. They're all the same system underneath.

Start your computer from the USB stick and pick Try Chamesle to use it without touching your disk, or Install Chamesle to put it on your computer. Read Before you start first. What's new.

What you need

  • a 64-bit PC from roughly the last 12 years (BIOS or UEFI both work)
  • 2 GB of RAM, 4 if you want lots of browser tabs
  • a USB stick of 4 GB or more (8 GB for Play)

Secure Boot has to be turned off for now.

Before you start

Trying Chamesle from the USB stick doesn't change anything on your computer. Installing it does, so before you pick Install Chamesle:

  • Back up your files to an external drive or a cloud service. Chamesle is still an early release.
  • Keeping Windows? If it uses BitLocker (most new laptops do), get your recovery key first, from aka.ms/myrecoverykey or a printout, or turn BitLocker off.
  • If you're not sure about any of this, stay in the live session and ask on the board first.

Making the USB stick

This wipes the stick, so copy anything you need off it first.

On Windows or macOS

Get balenaEtcher, pick the ISO, pick the stick, click Flash.

We haven't been able to test this on Windows ourselves yet. If something looks different or doesn't work, tell us on the board.

On Linux

Etcher works here too. Or from a terminal (check the device name with lsblk first, getting it wrong will wipe the wrong disk):

sudo dd if=chamesle-0.6.0-xfce-x86_64.iso of=/dev/sdX bs=4M status=progress conv=fsync

Ventoy

If you already use Ventoy, just copy the ISO onto the stick.

Booting it

Plug the stick in, restart, and open the boot menu. It's usually F12, F11, F8 or Esc right after you power on, depending on the computer. Pick the USB stick. You'll get a menu:

Try Chamesleuse it from the stick, nothing on your computer changes
Install Chameslegoes straight into the installer, Jiggity
More optionssafe graphics if you get a black screen, copy to RAM so you can pull the stick out (needs 4 GB+), and boot messages for when something goes wrong

Jiggity works like the Windows installer: pick a drive, or the free space next to Windows, tick encryption if you want it, and it installs and restarts. Your name, password and time zone come on the first start.

The live session logs in by itself as the user live. It has no password and can use sudo.

Checking the download

If you want to be sure the file isn't broken, compare its checksum with the one next to the download:

sha256sum -c chamesle-0.6.0-xfce-x86_64.iso.sha256

On Windows, certutil -hashfile chamesle-0.6.0-xfce-x86_64.iso SHA256 in a command prompt does the same.

We haven't been able to test this on Windows ourselves yet. If something looks different or doesn't work, tell us on the board.

In a virtual machine

VirtualBox, VMware, GNOME Boxes and QEMU all work. Give it 2 CPUs and 3 GB of RAM. With QEMU:

qemu-system-x86_64 -enable-kvm -m 3G -smp 2 -cdrom chamesle-0.6.0-xfce-x86_64.iso
