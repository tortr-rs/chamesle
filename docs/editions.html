The old desktops

Chamesle has no big desktops now, but it does have a graphical stage.

The old Chamesle shipped Xfce, KDE Plasma, Cinnamon, MATE, GNOME, an astronomy flavor, a console one and a server one. Those were the old system's packages and they went with it. The new Chamesle boots to a text login, and the graphical stage gives you X with a rio-style window manager.
