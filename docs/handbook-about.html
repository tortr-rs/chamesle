1. About Chamesle

1.1 What it is

Chamesle is a Linux distribution built from source that you put on a disk yourself, starting from the ISO. There is no installer: you install the root file system, write the configuration and the boot entry by hand. chamesle-disk partitions and formats the disk for you if you want, and this handbook goes through every other step.

The parts:

partwhat it is
kernela prebuilt Linux 6.18 LTS kernel with its modules
muslthe C library
riflethe coreutils, all in one C file; cat, ls, cp and the rest are links to one program
SPASthe package manager; its command is hoard. It builds from source and runs Gentoo's ebuilds
mkshthe shell, login shell and /bin/sh
initWinchester, /sbin/init, a shell script that runs under mksh, in the style of FreeBSD's: /etc/rc, /etc/init.conf, services
liminethe boot loader, BIOS and UEFI

Chamesle is made to be the most UNIX distribution possible. The coreutils are rifle's, the init is Winchester, and the rest is what Gentoo's ebuilds build: GNU software where a package needs it, bash for the ebuilds themselves.

The package repository is Gentoo's, on the musl profile, and hoard runs its ebuilds. Everything is built on the machine that installs it, so the first install takes a while (LLVM is the longest).

1.2 The layout of the system

/bin /sbin /lib     /lib holds the musl loader and the firmware
/usr/bin /usr/sbin  programs, /usr/lib libraries, /usr/share data, /usr/include headers
/usr/local/bin      yours, first in PATH
/boot               kernel, config, System.map, limine.conf (on the EFI partition)
/etc                configuration
/lib/modules        kernel modules, one directory per kernel version
/lib/firmware       firmware for the hardware, zstd compressed
/var/db/pkg         which package owns which file
/var/cache/distfiles  downloaded sources
/run /tmp           tmpfs, made new at every boot

The PATH of a login shell is /usr/local/bin:/usr/bin:/bin:/usr/sbin:/sbin. Packages install into /usr.

1.3 Where the sources are

directorywhat is in it
system/tools/ (chamesle-bootstrap, chamesle-chroot, chamesle-disk), files/ (init, rc and the services), iso/, this handbook
SimplePackagemAnagingSystem/SPAS: the Rust source of hoard, and src/ebuild.sh, the environment ebuilds run in
rifle/rifle.c, build.sh, tests/run.sh
Gentoothe ebuild tree, which hoard sync fetches (chapter 2)

The commands in this book assume the source trees are in $HOME/src/system, $HOME/src/SimplePackagemAnagingSystem and $HOME/src/rifle. Change the paths if yours are elsewhere.
