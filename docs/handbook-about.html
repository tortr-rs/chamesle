1. About Chamesle

1.1 What it is

Chamesle is a small Linux distribution on musl that you put on a disk yourself, from the ISO. There is no installer and nothing is compiled: chamesle-bootstrap puts the base into an empty root with the package manager, and you write the fstab, the password and the boot entry by hand. This handbook goes through every step.

The parts:

partwhat it is
kernela prebuilt Linux 6.18 LTS kernel with its modules
muslthe C library
magthe package manager, binary packages only, in one C file
riflethe coreutils, all in one C file; cat, ls, cp and the rest are links to one program
mkshthe login shell; /bin/sh is busybox's ash
initWinchester, /sbin/init, a shell script that runs under mksh, in the style of FreeBSD's: /etc/rc, /etc/init.conf, services
liminethe boot loader, BIOS and UEFI

Chamesle is made to be the most UNIX distribution possible, and to run on almost anything: the same base goes on a new laptop and on a Pentium 4 with 256 MB of memory. It is a system for the tty first. Anything else is a mag install away.

1.2 Where the packages come from

mag reads two kinds of repository, both signed:

  • Chamesle's own, at https://chamesle.org/repo: chamesle-base (Winchester, /etc/rc, the services, the tools of this book and the keys), mag and rifle
  • a large musl repository with everything else: the kernel, the firmware, the libraries, editors, compilers, X, about 28,000 packages for x86_64

Both are in /etc/mag/repos. A package is checked against the keys in /etc/mag/keys before anything of it is unpacked.

1.3 The layout of the system

/bin /sbin /lib     /lib holds the musl loader and the firmware
/usr/bin /usr/sbin  programs, /usr/lib libraries, /usr/share data
/usr/local/bin      yours, first in PATH
/boot               kernel, initramfs, limine.conf (on the EFI partition)
/etc                configuration; /etc/mag is mag's
/lib/modules        kernel modules, one directory per kernel version
/lib/firmware       firmware for the hardware
/var/lib/mag        which package owns which file
/var/cache/mag      downloaded indexes and packages
/run /tmp           tmpfs, made new at every boot

1.4 Where the sources are

directorywhat is in it
system/tools/ (chamesle-bootstrap, chamesle-chroot, chamesle-disk, and mkapk, mkrepo, mkpkgs for the repo), files/ (init, rc and the services), pkg/, keys/, iso/, this handbook
mag/mag.c, c.h, build.sh
rifle/rifle.c, build.sh, tests/run.sh

They are on github.com/tortr-rs.
