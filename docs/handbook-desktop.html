10. X and a window manager

10.1 What to install

mag install xorg-server xinit xf86-input-libinput mesa-dri-gallium font-dejavu windowmaker st
packagefor
xorg-serverX itself, with the modesetting driver, which drives Intel, AMD, NVIDIA and virtual graphics through the kernel
xinitstartx
xf86-input-libinputkeyboard, mouse and touchpad
mesa-dri-galliumOpenGL
font-dejavua font; X programs show empty boxes without one
windowmakerthe window manager, and WPrefs for its settings
sta terminal; xterm is another

Any other window manager or desktop in the repos goes the same way; only the line in ~/.xinitrc changes.

10.2 Firmware for the graphics

The kernel's graphics drivers load firmware for most cards. Install the one for yours and reboot:

graphicsfirmwareVulkan
Intel, up to 14th generationlinux-firmware-i915mesa-vulkan-intel
Intel Arc, Lunar Lake and newerlinux-firmware-xemesa-vulkan-intel
AMDlinux-firmware-amdgpu, linux-firmware-radeon for older cardsmesa-vulkan-ati
NVIDIAlinux-firmware-nvidiamesa-vulkan-nouveau

NVIDIA's own driver is built for glibc and is not in the repos. The open one, nouveau, runs every card; from the GTX 16 and RTX 20 on, the card's own firmware sets the clocks and it is fast, with Vulkan from NVK in mesa-vulkan-nouveau. On older NVIDIA cards it stays slow. lspci says which graphics a machine has.

10.3 Groups

There is no logind to hand the screen and the input devices to whoever logs in. X opens them as the user, so the user needs the video and input groups (6.5):

adduser alice video
adduser alice input

Log out and in again after.

10.4 startx

startx runs ~/.xinitrc, as the user, from a text login:

echo 'exec wmaker' > ~/.xinitrc
startx

X runs until wmaker ends: Exit in its menu. To start X at every login on tty1, at the end of ~/.profile:

[ "$(tty)" = /dev/tty1 ] && exec startx

Lines in .xinitrc before the exec run first, which is the place for the keyboard layout and the screen size:

setxkbmap fr
xrandr --output eDP-1 --mode 1920x1080
exec wmaker

mag install setxkbmap xrandr for those; xrandr alone lists the outputs and their modes.

10.5 Window Maker

The first start makes ~/GNUstep with Window Maker's settings. The right button on the desktop opens the menu, with programs, workspaces and Exit. The dock is in the top right corner and the clip, which switches workspaces, in the top left. Drag a program's icon to the dock to keep it there. WPrefs changes the rest: focus, themes, keys. The menu is ~/GNUstep/Defaults/WMRootMenu.

10.6 Firefox

mag install firefox

firefox-esr is the long-term one. Firefox and many other programs want a D-Bus session; with dbus and dbus-x11 installed and dbus enabled (6.2), start the window manager inside one:

exec dbus-launch --exit-with-session wmaker

10.7 When it fails

X writes ~/.local/share/xorg/Xorg.0.log; grep EE in it shows the errors.

what you seewhy, and what to do
open /dev/dri/card0: Permission denied, then no screens foundthe user is not in video (10.3)
no screens found with no permission errorno graphics driver came up; check ls /dev/dri, and the firmware (10.2)
no keyboard or mouse in Xxf86-input-libinput is not installed, or the user is not in input
X starts and ends at once~/.xinitrc is missing, or names a program that is not installed
boxes in place of lettersno font, font-dejavu
