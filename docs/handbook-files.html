11. File reference

11.1 On an installed system

pathwhat
/sbin/init, /etc/inittabbusybox init, which runs OpenRC
/etc/init.d/, /etc/runlevels/the services, and the ones started at boot
/usr/lib/chamesle/the boot scripts the services run
/etc/hostname, /etc/moduleshost name, modules loaded at boot
/etc/profilePATH, umask
/etc/passwd, /etc/shadow, /etc/group, /etc/shellsaccounts, passwords, groups, login shells
/etc/fstabfile systems
/etc/sysctl.d/kernel settings loaded at boot (6.10)
/etc/os-releaseNAME=Chamesle, ID=chamesle
/etc/mag/repos, keys/, arch, build.conf
/etc/mkinitfs/mkinitfs.confwhat goes into the initramfs
/boot/limine.confthe boot entries
/boot/limine-bios.syslimine's BIOS stage
/boot/EFI/BOOT/BOOTX64.EFIlimine for UEFI
/boot/vmlinuz-lts, initramfs-ltsthe kernel and its initramfs
/lib/modules/V/its modules
/lib/firmware/firmware
/var/lib/mag/what is installed, and its files
/var/cache/mag/indexes, downloaded packages and port trees
/usr/share/limine/limine's boot files, for installing it
/usr/share/doc/chamesle/handbook.mdthis book

11.2 In the sources

pathwhat
system/tools/chamesle-bootstrapputs the base into a root with mag
system/tools/chamesle-bootlimine.conf and limine for the system in a directory
system/tools/chamesle-diskcfdisk, vfat boot partition, ZFS root, mounted on /mnt
system/tools/mkapk, mkrepo, mkpkgspackages, signed indexes, Chamesle's own repo
system/files/the files in /etc and the tools, in chamesle-base
system/pkg/chamesle-base/its scripts, repos, os-release, issue
system/keys/the public keys the repos are signed with
system/iso/mkiso, mkinitramfs, initthe live ISO, its initramfs and the first process in it
system/iso/profile/packages, modules, limine.conf and the overlay/ of the live root
system/handbook/handbook.mdthis book
mag/mag.c, mag/c.h, mag/build.shthe package manager
rifle/rifle.c, rifle/c.h, rifle/build.shthe coreutils
rifle/tests/run.sh, rifle/tests/casesthe comparison tests

limine bios-install DEVICE
