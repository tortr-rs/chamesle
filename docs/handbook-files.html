10. File reference

10.1 On an installed system

pathwhat
/sbin/init, /etc/rc, /etc/rc.shutdowninit, the boot script, the shutdown script, all run by mksh
/etc/init.confhost name, boot services, modules, ttys
/etc/rc.d/, /usr/local/etc/rc.d/the service scripts
/etc/services, /etc/hostsport names and the local host name, the libc reads them
/etc/profilePATH, EDITOR, PAGER, umask
/etc/passwd, /etc/group, /etc/shellsaccounts, groups, login shells
/etc/fstabfile systems
/etc/os-releaseNAME=Chamesle, ID=chamesle
/etc/spas/hoard's configuration: make.conf, make.profile, repos.conf/, package.use and the rest (section 4.3)
/boot/limine.confthe boot entries
/boot/limine-bios.syslimine's BIOS stage
/boot/EFI/BOOT/BOOTX64.EFIlimine for UEFI
/boot/vmlinuz-V, config-V, System.map-Vthe kernel
/lib/modules/V/its modules
/lib/firmware/firmware
/var/db/pkg/the file list of each installed package
/var/cache/distfiles/downloaded sources
/usr/share/limine/limine's boot files, for installing it
/usr/share/doc/chamesle/handbook.mdthis book, on the live ISO
/var/db/repos/gentoo/the Gentoo tree, from hoard sync

10.2 In the sources

pathwhat
system/tools/chamesle-bootstrapmakes a root file system and builds the base set into it
system/tools/chamesle-chrootchroot with the pseudo file systems mounted
system/tools/chamesle-diskcfdisk, vfat boot partition, ZFS root, mounted on /mnt
system/files/init, rc, service, init.conf and the service scripts that go into every root
system/iso/mkinitramfsbuilds an initramfs
system/iso/initthe first process in the initramfs
system/iso/profile/packageswhat is in the live root
system/iso/profile/moduleswhat the initramfs loads
system/iso/profile/limine.confthe live boot menu
system/iso/profile/overlay/files copied over the live root
system/handbook/handbook.mdthis book
SimplePackagemAnagingSystem/src/hoard, in Rust, and ebuild.sh, the environment ebuilds run in
rifle/rifle.c, rifle/c.h, rifle/build.shthe coreutils
rifle/tests/run.sh, rifle/tests/casesthe comparison tests

10.3 Commands in short

chamesle-bootstrap [-s PACKAGES] [-n HOSTNAME] TARGET
mkinitramfs [-m modules] ROOTFS KVER OUT
hoard [--root DIR] install|upgrade|remove|autoremove|sync|search|info|list|files|owns|env-update|manifest|self-update
rifle --install DIR | --list
limine bios-install DEVICE
