7. The kernel and firmware

7.1 The kernel package

Nobody builds a kernel in Chamesle. linux-lts is a Linux 6.18 LTS kernel with a generic configuration that runs on most machines, and it installs

/boot/vmlinuz-lts
/boot/config-VERSION
/boot/System.map-VERSION
/lib/modules/VERSION/

linux-virt is a smaller one for virtual machines. Give it to chamesle-bootstrap with -k, and name its files in limine.conf (vmlinuz-virt, initramfs-virt).

7.2 Updating

mag update
mag upgrade

A new linux-lts replaces vmlinuz-lts and makes initramfs-lts again, so limine.conf needs no change. Reboot to run it; uname -r says what runs. Keep the ISO at hand in case a new kernel does not boot.

7.3 Modules

Modules are files in /lib/modules/VERSION. lsmod shows what is loaded, modprobe name loads a module with what it needs, modinfo name describes it. udev loads the ones the hardware asks for. Modules belong to one kernel build: after an upgrade of the kernel, reboot before loading any.

7.4 Firmware

The firmware is split by vendor, so a machine takes only what it uses:

packagefor
linux-firmware-intelIntel wireless (iwlwifi), Bluetooth and the rest of the intel folder
linux-firmware-i915Intel graphics
linux-firmware-amdgpu, linux-firmware-radeonAMD graphics
linux-firmware-rtlwifi, linux-firmware-rtw88, linux-firmware-rtw89, linux-firmware-rtl_nicRealtek wireless and ethernet
linux-firmware-ath10k, linux-firmware-ath11k, linux-firmware-ath9k_htcQualcomm Atheros wireless
linux-firmware-brcmBroadcom wireless
linux-firmwareall of them, over 500 MB
linux-firmware-nonenone

mag search linux-firmware lists them. If dmesg says a firmware file failed to load, mag owns is no help yet, since it is not installed; the name of the file says the vendor.

7.5 The initramfs

The kernel package makes /boot/initramfs-lts with mkinitfs whenever the kernel is installed or updated. What goes into it is set in /etc/mkinitfs/mkinitfs.conf:

features="ata base cdrom ext4 keymap kms mmc nvme raid scsi usb virtio"

For a root on ZFS add zfs to the list, install zfs and zfs-lts, and make it again:

mag install zfs zfs-lts
mkinitfs $(ls /lib/modules)

The initramfs reads root=, rootfstype= and modules= from the command line, mounts the root and starts /sbin/init. If it cannot, it says why and gives a shell.

The live ISO has its own initramfs, made by iso/mkinitramfs, which mounts the squashfs (chapter 8).
