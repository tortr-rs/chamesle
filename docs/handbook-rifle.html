5. rifle

5.1 What it is

rifle is the coreutils of Chamesle in one C file, rifle.c, on c.h, a one-file libc. It has no GNU code in it and no libc under it. It sorts and compares by bytes, always; there are no locales.

There is one program. cat, ls, cp and the other commands are links to it, and it runs whichever name it was called by. You type cat, not rifle cat.

5.3 Building

cd $HOME/src/rifle
./build.sh

builds rifle with clang and lld (CC overrides cc) and makes the links in bin/. To put the links anywhere:

rifle --install /usr/bin
rifle --list                   the names it knows

5.4 Tests

tests/run.sh                   all the cases
tests/run.sh sort              the cases that have `sort` in them

Each case in tests/cases runs once under GNU coreutils and once under rifle, and what they print and how they exit are compared. The machine that runs the tests therefore has GNU coreutils for the comparison; the installed system does not. ./build.sh has to have run first. A case that starts with @ro runs with the whole file system read-only under bwrap, and is skipped when bwrap is missing.

SPAS has tests of its own, in its sources (cargo test).
