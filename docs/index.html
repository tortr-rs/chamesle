What is Chamesle

Chamesle is a Linux distribution built from source and installed by hand, like Gentoo or Linux From Scratch. The kernel is Linux. Nothing else in it is GNU. It is text mode: there is no desktop.

Components

partwhat it is
kernelLinux 6.18 LTS, a prebuilt distribution kernel, boots on BIOS and UEFI
muslthe C library
riflethe coreutils, one C file. 87 tools, 810 test cases against GNU's
magthe package manager, one C file. Builds from source, reads NetBSD pkgsrc as it is
pkgsrcthe package repo, plus our own recipes where pkgsrc has none
mkshthe shell, also /bin/sh
inita shell script in the FreeBSD style, set up in /etc/init.conf
liminethe boot loader
vimthe editor

Install

By hand, from the handbook. From any running Linux, mount a disk and run the bootstrap into it, then set up fstab and limine (chapter 5). Or build the live ISO and boot that (chapter 4). There is no prebuilt ISO to download: you build it.

chamesle-disk /dev/sda
chamesle-bootstrap -n yourhostname /mnt
iso/mkiso -r $HOME/src/mag/repo:/usr/pkgsrc

The commands, one after the other, are on the install page.

Questions

Is there an ISO to download?
No. You build it with iso/mkiso. Anything older with Chamesle's name on it is the old distro, not this system.
Where is the code?
There is no public source repo yet. The old Chamesle code is on GitHub, and none of it is in the new system. Chamesle Source is a side project with its own repo.
What license?
Not decided. The packages mag builds keep their own licenses.
No GNU at all?
Nothing GNU is installed. A few GNU build tools (gmake, bison, flex, m4) are used while some packages are built, and they are not part of the system.
Why start over?
The old Chamesle was mostly other people's software with our paint on it. About has more.
