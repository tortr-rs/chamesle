What is it?

Chamesle is a Linux distribution for people coming from Windows. It's built on Void Linux and one person makes it.

It goes next to Windows if you want to keep Windows, or on the whole disk. .deb, .rpm, .exe and .msi files open with a double-click. The Driver Manager sorts out NVIDIA cards and the Wi-Fi chips that need it. And before every update it takes a snapshot of the system, so if an update breaks something you pick "before the update" in the boot menu and you're back.

It's free. It's also still early, so back up your files before you put it on a computer you care about.

News

November 8, 2026 NEW
We started X8664, our own X server: XFree86 4.8, forked and brought up to date, so X can be as smooth as Wayland. By the evening it built on today's compiler and ran dwm, and by night it drew on a screen through the kernel. By the afternoon it had keyboards, page flips (no more tearing) and the Present extension, so programs can draw in time with the monitor, and then compositing, so window shadows and see-through windows work. In the evening mice and touchpads went over to libinput. See it. Nothing to download yet.
No more weekly updates. The package repo now moves forward every six months, so things stop changing under you. Security fixes still go out straight away.
The key that signs the package repo changed. If sudo apk update says UNTRUSTED signature, there's a one-line fix on the what's new page.
October 28, 2026
0.7 "Be Kool" is out. New look, Oxygen icons, and a Store with screenshots, reviews and firmware updates for your BIOS and SSD. After this: fixes only until 0.8.
October 26, 2026
0.6: one download for every desktop. Jiggity, our own installer, asks everything first and then installs the desktop you picked.

Coming up
