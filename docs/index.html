What is Chamesle

Chamesle is a Linux distribution built from source and installed by hand, like Gentoo or Linux From Scratch. The kernel is Linux. Nothing else in it is GNU. It boots to a text login, and the graphical stage starts X with 9wm, a window manager like Plan 9's rio, with 9term, acme and sam.

News

Stages are out. The base stage is the whole system in one tarball: unpack it, chroot, and let hoard build the rest. The graphical stage adds Xorg and starts 9wm with 9term, acme and sam on the first login. The handbook covers both.

Chamesle starts over. The old Debian-style desktop distro is gone, with its desktops and the 0.8 release. The new one is written from scratch. The handbook has the install steps: partition, mount, chamesle-bootstrap, fstab and limine.

The old Chamesle went on hold. X8664 became X22 and got a site of its own. The news page has the history of the old releases.

Components

partwhat it is
kernelLinux 6.18 LTS, a prebuilt distribution kernel, boots on BIOS and UEFI
muslthe C library
riflethe coreutils, one C file. 113 tools, more than 1700 test cases against GNU's
SPASthe package manager, its command is hoard. Builds from source, runs Gentoo's ebuilds
ebuildsthe package repo, Gentoo's, on the musl profile
mkshthe shell, also /bin/sh
Winchesterthe init, a shell script in the FreeBSD style, set up in /etc/init.conf
liminethe boot loader
samthe editor, from Plan 9 (sam -d is $EDITOR)

Install

Boot the ISO or unpack a stage, and install by hand from the handbook (chapter 3). Or, from any running Linux, mount a disk and run the bootstrap into it.

chamesle-disk /dev/sda
chamesle-bootstrap -n yourhostname /mnt

The commands, one after the other, are on the install page.

Questions

Is there an ISO to download?
Yes, chamesle.iso. Anything older with Chamesle's name on it is the old distro, not this system.
Where is the code?
There is no public source repo yet. The old Chamesle code is on GitHub, and none of it is in the new system. Chamesle Source is a side project with its own repo.
What license?
Not decided. The packages SPAS builds keep their own licenses.
No GNU at all?
Nothing GNU is installed. A few GNU build tools (gmake, bison, flex, m4) are used while some packages are built, and they are not part of the system.
Why start over?
The old Chamesle was mostly other people's software with our paint on it. About has more.
