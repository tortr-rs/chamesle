What is Chamesle

Chamesle is a small Linux distribution on musl, installed by hand. Nothing is compiled: the package manager, mag, installs binary packages, and chamesle-bootstrap puts the base on a disk the way debootstrap does. The init is Winchester, the coreutils are rifle, the shell is mksh. It boots to a text login, and it runs on a new laptop as well as on a Pentium 4 with 256 MB of memory.

News

2026-11-21
No more building. mag is now a binary package manager, one C file, and reads signed repos with about 28,000 packages for x86_64 and 32-bit x86. There is no stage any more: boot the ISO, run chamesle-bootstrap /mnt, and write the fstab and the boot entry by hand. Chamesle's own packages are in its repo at chamesle.org/repo. The handbook is rewritten for it.

Components

partwhat it is
kernelLinux 6.18 LTS, prebuilt, boots on BIOS and UEFI
muslthe C library
magthe package manager, binary packages only, one C file. Checks every package against its signature
riflethe coreutils, one C file. 113 tools, more than 1700 test cases against GNU's
mkshthe login shell
Winchesterthe init, a shell script in the FreeBSD style, set up in /etc/init.conf
liminethe boot loader

Install

Boot the ISO and install by hand from the handbook (chapter 3): partition, mount, then

chamesle-bootstrap -n yourhostname /mnt

and write the fstab, the password and limine.conf. For a 32-bit machine there is chamesle-x86.iso.

Questions

Where is the code?
On GitHub: system (init, tools, ISO, handbook), mag and rifle.
Where do the packages come from?
Chamesle's own (the base, mag, rifle) from its repo. Everything else, the kernel included, from a large musl binary repo that mag reads as it is. Packages has more.
What license?
Not decided. The packages keep their own licenses.
Why start over?
The old Chamesle was mostly other people's software with our paint on it. About has more.
