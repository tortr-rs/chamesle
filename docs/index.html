What's on it

  • Firefox, a file manager, printing, Bluetooth, Wi-Fi and laptop firmware, installed.
  • The Chamesle Store: Flathub and our own repo in one window.
  • .deb, .rpm, .exe and .msi files open with a double-click.
  • The Driver Manager sets up NVIDIA and some Wi-Fi chips.
  • Jiggity, the installer: next to Windows or the whole disk, encrypted if you like.
  • Updates once a week, held back a while first. They can be undone.
