What is Chamesle

Chamesle is a small Linux distribution on musl. Nothing is compiled: the package manager, mag, installs binary packages, and chamesle-bootstrap puts the base on a disk the way debootstrap does. The init is OpenRC, the coreutils are rifle, the shell is mksh. It boots to a text login, and it runs on a new laptop as well as on a Pentium 4 with 256 MB of memory.

Components

partwhat it is
kernelLinux LTS, prebuilt, boots on BIOS and UEFI
muslthe C library; or glibc, on Artix, Arch and the AUR, for NVIDIA and Steam (1.3)
magthe package manager, binary packages only, one C file. Checks every package against its signature
riflethe coreutils, one C file. 113 tools, more than 1700 test cases against GNU's
mkshthe login shell
OpenRCthe init, every package brings its service, turned on with rc-update add
liminethe boot loader

Install

Boot the ISO and run

chamesle-install

It asks for the disk, ZFS, btrfs or ext4, limine or GRUB, the firmware, a host name and a user. Or do it by hand from the handbook (chapter 3). For a 32-bit machine there is chamesle-x86.iso.

Questions

Where is the code?
On GitHub: system (init, tools, ISO, handbook), mag and rifle.
Where do the packages come from?
Chamesle's own (the base, mag, rifle) from its repo. Everything else, the kernel included, from a large musl binary repo that mag reads as it is. Packages has more.
What license?
Not decided. The packages keep their own licenses.
Why start over?
The old Chamesle was mostly other people's software with our paint on it. About has more.
