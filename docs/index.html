Linux for people who just want their computer to work.

Chamesle is a desktop Linux distro. You boot it, it looks like what you're used to, and you get apps from Flathub without hunting around. If you like poking at things there's a full package manager underneath, but you never have to touch them.

Get 0.1 "Margit" Xfce edition, 64-bit, 1.8 GB

What you get

Out of the box: Firefox, a file manager, Flathub already set up, printing, Bluetooth, Wi-Fi, and the firmware and drivers most laptops need. An installer, an app store and a driver manager are next on the list.

Under the hood it uses dinit to start things, so it boots fast and doesn't get in your way. There's no telemetry. There's no account to sign into.

Packages

Starting with the next release, Chamesle uses apk:

sudo apk update
sudo apk add gimp
sudo apk upgrade

Packages come from our own signed repository. They're built from Void Linux's glibc packages, so there's a lot of them.

Download

Chamesle 0.1 Xfce (x86_64)

Write it to a USB stick with Etcher or Ventoy, boot from it, and you're in a live session. It doesn't touch your disk. (There's no installer in 0.1 yet.)

Needs a 64-bit PC, 2 GB of RAM (4 is nicer). The live session runs from the stick. This is an early release, so expect rough edges and tell us about them.
