What's new in 0.2

0.2 is out. Get it from the download page.

Since the release

Being rolling means 0.2 keeps getting better without a new ISO. Since it came out:

  • A Cinnamon edition. Linux Mint's own desktop, next to Xfce and MATE. Have a look.
  • An update notifier. A small icon shows up next to the clock when there are updates. Click it, type your password, done. It covers system packages and Flathub apps.
  • Driver Manager. It looks at your hardware and tells you if something works better with another driver: NVIDIA cards (it picks the right driver for how old the card is), some Broadcom Wi-Fi chips, HP printers, VirtualBox and VMware. One click, then a restart.
  • The store shows a progress bar while it downloads, so big apps don't look stuck.
  • Fixed: some Flathub apps wouldn't install and showed a long error about a kernel module.

Already running 0.2? sudo apk upgrade gets the fixes. The two new apps are separate packages, so add them once:

sudo apk add chamesle-updater chamesle-drivers chamesle-base

The Cinnamon ISO already has all of it. New Xfce and MATE ISOs with it are coming soon (0.2.1).

pkgimport: .deb and .rpm, just double-click

Most Linux apps on the web come as a .deb (Ubuntu, Debian) or an .rpm (Fedora, openSUSE). On Chamesle you don't have to care which. Double-click either one and pkgimport installs it: it converts the package, pulls in the libraries it needs from the Chamesle repo, and adds it to your menu. Updating and removing works like any other package.

sudo pkgimport install ~/Downloads/app.deb
sudo pkgimport install ~/Downloads/app.rpm

The Chamesle Store

One window for all your apps: Flathub and the Chamesle repo together, with categories, search and an Updates tab that updates everything with one button. If an app is on both, you choose which one you want. It installs .deb and .rpm files too. It's the first version, so tell us what's missing on the board.

A MATE edition

Next to Xfce there's now a MATE edition, with the same Chamesle look and Linux Mint's MATE start menu. Compare them.

An installer

0.1 was live-only. 0.2 puts Chamesle on your disk. Double-click Install Chamesle on the desktop and answer a few questions: language, keyboard, where it goes, your name and password. Then it does the rest.

  • Next to Windows. The installer can shrink a Windows partition to make room, and you choose Windows or Chamesle every time the computer starts.
  • Or the whole disk, if you're done with what's on it.
  • Encryption with one tick box. Your files stay locked if the laptop gets stolen.
  • Manual partitioning for people who want it, with ext4, btrfs or xfs.
  • Works on both old BIOS machines and UEFI.

The Chamesle repo

The system now uses apk and the Chamesle repo: almost 15,000 packages, each one signed with the Chamesle key. Updating everything is one command:

sudo apk upgrade

Search the packages.

Stable rolling

From 0.2 Chamesle is a rolling release that's careful about it: updates every week, new versions held back for a while before they go out, and a test install that has to boot before anything ships. The kernel is pinned to the long-term support line (6.18 now). New ISOs come every 6 months.

Smaller things

  • A new 4K wallpaper, the Inter font and Papirus icons.
  • The login screen is Mint's, with the Chamesle logo.
  • Qt apps use the same theme as everything else.
  • fastfetch shows the Chamesle logo.
  • The boot menu of an installed system finds Windows and other systems on its own.
