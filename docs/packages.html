Packages

Binary packages, signed, installed with mag.

mag is the package manager. It reads two repos: Chamesle's own, with chamesle-base, mag and rifle, and a large musl repo with everything else, about 28,000 packages for x86_64 and as many for 32-bit x86. Every index and every package is checked against the keys in /etc/mag/keys before anything is unpacked.

mag update
mag install tmux
mag remove tmux
mag upgrade
mag search word

Before this, mag built from pkgsrc, then SPAS ran Gentoo's ebuilds. Both meant compiling for hours on every machine, so now nothing is built at all.

Chamesle's repo

chamesle.org/repo, for x86_64 and x86, with a search over every package mag can install. The packages are made with mkapk and mkrepo from system, and signed with chamesle-20261118.rsa.

Missing something?

mag search first. If it is not there, tell us on the board.

Something wrong on this page? Tell us on the board.
Chamesle installs with chamesle-install, or by hand from the handbook.
