Packages

Packages come from NetBSD's pkgsrc, built from source with mag.

The repo is pkgsrc, read as it is, plus a small set of our own recipes for things pkgsrc doesn't have. There are no binary packages yet: mag install downloads the source, checks the checksum, builds it and installs it, dependencies first.

mag install editors/vim
mag remove vim
mag upgrade
mag search word

There's no web search for the repo yet. The old one listed the old apk packages, which don't exist in the new system, so it's gone. The rest is in the handbook.

Two kinds of package

  • Our own recipes: a file with a url, a sha256, deps and plain sh steps.
  • pkgsrc packages: a directory with a Makefile, a distinfo and patches/. mag reads them without bmake.

Both can be mixed in the same repo path. Nothing is installed over a file that another package owns, and files in /etc you changed stay as they are.

Missing something?

If pkgsrc has it, mag can usually build it. If it doesn't build, tell us on the board.
