Packages

Find software in the Chamesle repo, and the three ways to install it.

The easiest way is the Store in the menu: it shows apps from Flathub and from the Chamesle repo together. Under the hood there are three ways to get software on Chamesle.

Flathub is the easy one: it's already set up, apps are sandboxed, and they update on their own. Use it for desktop apps like Spotify, Discord, Steam or OBS.

flatpak install flathub com.spotify.Client

apk is the system package manager. It's what the system itself is made of, and it has everything from desktop apps to compilers and servers. From 0.2 on, Chamesle uses apk (0.1 still uses xbps underneath).

pkgimport is for everything else: if an app only comes as a .deb or .rpm, double-click it. More below.

    Using apk

    sudo apk updateget the latest package list
    sudo apk upgradeupdate everything
    sudo apk add gimpinstall something
    sudo apk del gimpremove it
    apk search -v paintsearch by name
    apk info -a gimpdetails about a package
    apk info --who-owns /usr/bin/gimpwhich package a file came from

    pkgimport: .deb and .rpm files

    Downloaded a .deb or .rpm from a website? Double-click it. Chamesle converts it to a normal package and installs it, and the libraries it needs come from our repo. Or in a terminal:

    sudo pkgimport install ~/Downloads/something.deb

    Remove it like anything else, with sudo apk del NAME. Most apps work this way. If one was built for a library version we don't have, pkgimport says which one, and the Flathub version is the way to go.

    The repository

    Packages are hosted on SourceForge and signed with the Chamesle key. On a Chamesle system, /etc/apk/repositories has this line:

    v3 https://downloads.sourceforge.net/project/chameslerepos

    There are almost 15,000 packages and they're kept up to date. The public key is on GitHub.
