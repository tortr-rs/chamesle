Packages

Packages are Gentoo's ebuilds, built from source with hoard.

The repo is Gentoo's, on the musl profile. hoard is the package manager from SPAS: it reads the ebuilds, resolves the dependencies, runs them in bash and merges the result. There are no binary packages yet.

hoard sync
hoard install app-misc/fastfetch
hoard remove fastfetch
hoard upgrade
hoard search word

We started on pkgsrc with our own package manager, mag. It kept breaking on small things, one package after another, so we're moving to ebuilds. This is still being set up: a first dry run on Chamesle reads the tree and resolves dependencies, and the builds are what's being worked on.

Missing something?

If Gentoo has it, hoard can usually build it. If it doesn't build, tell us on the board.

Something wrong on this page? Tell us on the board.
