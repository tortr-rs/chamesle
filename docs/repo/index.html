The repo

https://chamesle.org/repo has Chamesle's own packages, for x86_64 and x86. mag reads it next to the musl repo with everything else; both are in /etc/mag/repos of every install. The index and every package are signed with chamesle-20261118.rsa.pub, whose key has the SHA-256 45694a25d1299eaa555d6bf2e661b49d26db8e6883d6ac92ac1a4c0c9de5c187
